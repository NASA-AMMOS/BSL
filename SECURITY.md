# Security Policy

## Supported Versions

These versions of BSL are currently being supported with security
updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.0   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

To report a vulnerability, create a new ticket under the Issues
tab > New Issue button. Give the ticket a descriptive title and 
put as much info as possible in ticket description like how to
recreate the bug. Assign the ticket a "bug" label (from right sidebar) 
and a Criticality label (CRIT-1, CRIT-2, etc.) for severity of issue.
